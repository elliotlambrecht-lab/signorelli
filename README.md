# Signorelli dashboards

Private site for Signorelli. Every page is locked with a password (or, for the staff bonus page, a personal code).

- `index.html` / `home.html`: welcome page. Asks who is logging in, then opens the hub for that role.
- Owners (Rebecca and Elliot): cash, profitability, shop operations, plus everything managers and store staff see.
- Managers: shop performance, labour and rota, scorecard, team bonus tracker, front of house, kitchen.
- Store staff (shop iPads): front of house (`foh.html`) and kitchen screen (`kitchen.html`).
- `me.html`: each employee's own bonus page, opened from their personal link on their own phone.

Owner and manager sessions end after 15 minutes without a tap. Front of house and the kitchen screen open in the shop view; the manager view needs the manager password each time.
